# Data
* Files: `data/real_estate_valuation.xlsx` (original UCI file) and `data/real_estate_valuation.csv` (renamed columns, no index).
* 414 sales, Aug 2012 – Jul 2013, Sindian (Xindian) District, New Taipei City, Taiwan. No missing values or duplicates.
* Columns: `transaction_date` (decimal year, e.g. 2013.250 = March 2013), `house_age` (years), `dist_mrt` (metres to the
  nearest MRT station), `n_stores` (convenience stores in the living circle on foot), `latitude`, `longitude`,
  `price_per_ping` (10,000 New Taiwan Dollars per ping; 1 ping = 3.3058 m²).
* Source: UCI Machine Learning Repository, dataset 477, doi:10.24432/C5J30W. Licence **CC BY 4.0** → redistributed with attribution.
* Citation: Yeh, I-C. & Hsu, T-K. (2018), *Applied Soft Computing* 65, 260–271.
